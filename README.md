## To deploy to GitHub Pages

From this repository's root:

```bash
npm install
npm run deploy
```

`npm run deploy` builds the `dist` folder and publishes it to the `gh-pages` branch. The live app is [https://sbecker11.github.io/munsell-color-space-explorer/](https://sbecker11.github.io/munsell-color-space-explorer/). GitHub Pages can take about a minute to show the new build.
